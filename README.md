# Discord Spoofer

أداة Python لتضخيم playtime والـ badges على Discord.

## المميزات
- تضخيم ساعات اللعب (Playtime)
- تفعيل شارات الألعاب (Game Badges)
- دعم User Token و cf_clearance
- إرسال أحداث إلى `/api/v9/science`

## المتطلبات
- Python 3.8+
- requests
- discord.py
